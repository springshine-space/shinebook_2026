## 폴더 구조

```text
shine-book/
├── assets/
│   ├── flipbook.css     # 공통 스타일 (모든 작가가 함께 사용)
│   ├── flipbook.js      # 공통 기능 (모든 작가가 함께 사용)
│   └── logo.webp        # 뒷표지에 들어가는 스프링샤인 로고
├── green/               # 작가별 폴더 (영문 소문자)
│   ├── index.html       # 이 작가의 플립북 페이지
│   ├── thumb.webp       # 홈페이지 카드용 정사각 썸네일
│   └── pages/           # 페이지 이미지 (01.webp, 02.webp ...)
├── .gitignore
├── .nojekyll
└── README.md
```

## 게시 주소

GitHub Pages로 게시되며, 작가별 주소는 아래 형식입니다.

```text
https://(계정명).github.io/shine-book/(작가폴더명)/
```

특정 쪽을 바로 열려면 주소 끝에 `#쪽번호`를 붙입니다. (예: `.../green/#6`)

## 작가 추가 방법

1. `green` 폴더를 복사해 새 폴더명(영문 소문자)으로 바꿉니다.
2. 새 폴더의 `pages/` 안 이미지를 새 작가의 페이지 이미지로 교체합니다. (파일명은 `01.webp`, `02.webp` 순서)
3. `thumb.webp`를 새 작가 썸네일로 교체합니다.
4. 새 폴더의 `index.html`에서 `<title>`, 화면 하단 이름(`id="name"`), 그리고 `window.FLIPBOOK` 안의 `title`, `artist`, `pages`, `copyright`를 수정합니다.
5. 홈페이지 shine book 페이지의 작가 목록(`writers`)에 새 작가의 주소를 추가합니다.

## 이미지 작업 기준

- 형식: WebP (용량 절약)
- 크기: 한 페이지 가로 1100px 내외
- 쪽 번호는 PDF 순서와 같게: 1쪽은 표지, 2쪽부터 2장씩 펼침면(2–3, 4–5 ...)으로 보입니다.
- 원본 PDF와 고해상도 파일은 이 저장소에 올리지 않고 별도로 보관합니다.
